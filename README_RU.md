# SPECTRUM AI

Стартовое Android-приложение для поиска по открытым источникам: интернет, новости и публичная поисковая выдача по доменам. Запросы открываются во внешнем браузере. Приложение не подключается к закрытым базам, банковским системам или государственным аккаунтам.

Сборка: JDK 17, Android Gradle Plugin 8.7.3, Android SDK 35. Запустите workflow из codemagic.yaml.
